GETTING STARTED

Make your first cutscene

  1. Start the phone bridgeRight panel → Start phone bridge. This is the local server both Studio and your phone talk to. Allow it through Windows Firewall if prompted.
  2. Connect StudioIn Roblox Studio open the Cineflow panel and click Connect to desktop app. The top-right dot turns green when it is live.
  3. Add clipsPress ＋ on a track, or use Quick add. Camera keys take yaw / pitch / roll, animations take a rig name and an animation ID, triggers fire on a part.
  4. PreviewPress Preview (or Space) to watch it in Studio. Optional: connect your phone as a handheld camera and record a take with Start take.
